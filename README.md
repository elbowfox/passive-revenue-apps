# Passive Revenue Generators – Built by AI

These are practical, deployable tools designed for passive or semi-passive income. They are **Bring Your Own Key (BYOK)** so there are zero ongoing AI costs for you. Host for free and charge users later via Stripe or Gumroad.

## 1. ReviewReply AI (Web App)
**Path:** `review-reply-ai/`
- Instant professional replies to Google/Yelp reviews.
- Target: Local businesses, restaurants, dentists, salons.
- Monetization: Free with BYOK → later $9–29/mo for managed key + analytics.
- Deploy: Upload folder to **Cloudflare Pages** or **Netlify** (commercial use allowed on free tier).

## 2. Page Summarizer Chrome Extension
**Path:** `page-summarizer-ext/`
- One-click AI summary of any webpage.
- Monetization: Free BYOK → Chrome Web Store + paid tier or affiliate.
- Install: Load unpacked in Chrome (`chrome://extensions` → Developer mode).
